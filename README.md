# Quick Launch Hub V3

A lightweight, highly customizable desktop application for Windows, designed to give you instant access to your most-used apps, folders, and web links. Simplify your digital life with one centralized hub.

---

## 🚀 Key Features

* **Instant Access:** Launch applications, system commands (`cmd`, `notepad.exe`), or open web URLs with a single click.
* **Built-in Shortcut Editor:** Easily add, modify, or delete your custom shortcuts without touching any configuration files.
* **Quick Search & Launch:** Type to instantly filter your list, or hit Enter to perform a quick online search via the selected engine.
* **Customizable Themes:** Supports multiple color themes (Light, Dark, Blue) for personalized aesthetics.
* **Persistent & Minimalist:** Can be pinned on top of other windows for constant availability.
